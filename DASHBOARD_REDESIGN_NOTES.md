# Choivia — Dashboard redesign

This version refreshes the Dashboard with the selected visual direction:
- Playful + soft 3D botanical style
- A custom SVG plant companion that changes growth stage with overall progress
- A dynamic next-step card based on saved guide progress
- A decision-helper entry point and illustrated guide cards

## Run locally

1. Extract the project.
2. Run `npm install`.
3. Run `npm run dev`.

The redesign changes `src/App.jsx` and appends Dashboard-scoped styles to `src/App.css`.
Existing guide data, routes, localStorage schema, and other pages are retained.
